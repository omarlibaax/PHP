# Week 3 Assignment

This assignment contains a PHP practice file, [Assigment.php](Assigment.php), covering basic programming logic, conditions, loops, and number operations.

## What the Assignment Includes

The file contains solutions for the following tasks:

1. Find the largest and smallest of three integers.
2. Check if a number is divisible by 3, 5, or both.
3. Print odd numbers from 2 to 20 and even numbers from 35 to 7.
4. Print numbers divisible by both 2 and 5 from 50 down to 2.
5. Reverse a number using arithmetic operations.
6. Find the LCM of two positive integers.
7. Find the HCF of two integers.
8. Generate a multiplication table from 1 to 12 using nested loops.
9. Check whether a number is prime or not.
10. Print all prime numbers between 10 and 50.

## Run the Program

1. Start Apache in the XAMPP Control Panel.
2. Open the PHP file in a browser using:

```text
http://localhost/PhpCourse/Week3/Assigment.php
```

## Check PHP Syntax

From the project folder, run:

```powershell
C:\xampp\php\php.exe -l Week3\Assigment.php
```

If the script is valid, PHP will report:

```text
No syntax errors detected in Assigment.php
```
